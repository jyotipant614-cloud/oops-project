# OOPS Practicals – 5th Semester (Java)

This repository contains all 10 Java programs from the OOPS practical sheet.

## Requirements
- Java JDK 8 or later

## Run a practical
Open a terminal in the practical's folder. Example:

```bash
cd Practical-01-Classes-and-Objects
javac Practical1.java
java Practical1
```

For the other folders, compile and run the matching class: `Practical2`, `Practical3`, ... `Practical10`.

## Practical list
1. Classes and Objects
2. Single, Multilevel, and Hierarchical Inheritance
3. Hybrid and Multiple Inheritance Using Interfaces
4. Method Overloading and Method Overriding
5. Simulating Operator Overloading Using Methods
6. Default, Parameterized, and Copy Constructors
7. Object Lifecycle and Garbage Collection
8. Constructor Overloading
9. `this` Keyword, Constructor Chaining, and Static Members
10. Encapsulation Using Getters, Setters, and Validation
